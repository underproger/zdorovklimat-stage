# zdorovklimat — stage

Стейдж-копия сайта zdorovklimat.com.ua (MODX Revolution 2.5.7, miniShop2, Babel: UA + RU).

- Стейдж: https://zdorovklimat-stage.touchit.vinnica.ua/
- Папка на сервере: `/home/ti061721/touchit.vinnica.ua/zdorovklimat-stage/`
- Менеджер: `/impulsemanager/`
- Префикс таблиц: `Impulse_Digital_X_`

## Что не хранится в git

| Что | Почему |
|---|---|
| `core/config/config.inc.php`, `config.core.php`, `connectors/config.core.php`, `impulsemanager/config.core.php` | у каждого окружения свои пути и доступы к БД — кладутся на сервер вручную |
| `rest.php` | содержит доступы к Bitrix24 CRM (репозиторий публичный) |
| `assets/images/` и прочие загрузки | фото переносятся отдельно |
| `core/cache/` | кэш MODX, создаётся сам |

## Деплой на стейдж

1. `git pull` в папке сайта.
2. Если менялась база — импортировать выданный дамп.
3. Очистить кэш: удалить содержимое `core/cache/` (или «Обновить сайт» в менеджере).

## PHP

MODX 2.5.7 не работает на PHP 8+. На хостинге нужен PHP 7.x (локально проверено на 7.4).

- Шаблоны и чанки — **статические**: правка в менеджере записывает изменения в файл на сервере, поэтому такие правки нужно коммитить (или делать их в git).
- Шапка прозрачная поверх тёмного первого экрана на страницах из списка `$darkHero` в `zk.layout.tpl` (сейчас главная, «Про нас», «Відео», «Об’єкти» и направления), на остальных — сплошная (`.header.solid`).
- Якорные ссылки пишем как `{$zk.self}#id` — из-за `<base href>` голый `#id` ведёт на главную.
- Объекты на главной — TV **«Об’єкти на головній»** (`home-objects`) у ресурсов 1 и 1288: ID через запятую, порядок сохраняется. Пусто — 6 последних объектов.
- Логотипы клиентов — существующий MIGX TV `migx_logo` ресурса 1 (блок партнёров на любой странице берёт их оттуда).
- Ліцензії на «Про нас» — существующий MIGX TV `migx_sertificat` (файлы в `assets/images/all/`), клик открывает просмотр с листанием.
- Поле «Содержимое» страницы «Про нас» новым шаблоном не выводится: весь текст страницы разложен по блокам в `about.inc.php`.
- Видео — существующий MIGX TV `objects-video-list` (название, ID YouTube, обложка). Сетка в 3 колонки; первое видео запускается кнопкой на первом экране. Без обложки берётся превью с YouTube.
- Контакты: телефоны, email, YouTube, Facebook — из ClientConfig; карта — iframe из ClientConfig «google-map»; Viber/Telegram и ссылка на Google Maps — в `$zk` в `zk.layout.tpl`.
- Блог: все статьи одной сеткой без пагинации (статей мало). Картинка карточки — TV `img-blog-prew`; обложка статьи — `img-blog-banner`, но только если этой картинки нет в тексте статьи. Зміст строится скриптом по заголовкам `h2`. Просмотры — `HitsPage`, комментарии (easyComm) на новом дизайне не выводятся (их не было).
- Внутри некешированных MODX-тегов в шаблонах не используем Fenom-синтаксис `{...}` в параметрах (в т.ч. `@INLINE`): некешированная часть проходит Fenom повторно и `{$var}` превращается в пусто.
- Объекты: карточка — TV `object-img` (обложка) и `object-date` (год); короткие названия направлений — lexicon `zk.cat.<id>`. Галерея объекта — ms2Gallery (как раньше), большое фото открывается с водяным знаком `assets/images/design/watermark_obgekt_page_box.png`. «Місце зведення…» берётся из текста объекта в факты первого экрана; ссылки на YouTube в тексте становятся кнопкой видео. Карта объектов — Google My Maps из ClientConfig `google-map_object`, легенда — иконки `assets/images/map/_icon_*.png`. На общей странице и в направлениях показываются первые 12 объектов, дальше — «Показати ще».
- Переменные, заданные внутри `{include}`, обратно в шаблон не возвращаются — общие данные считаем в самом шаблоне (см. `video.tpl`).
- Форма заявки: AjaxForm + FormIt (`spam,email,FormItSaveForm`), письмо — чанк `zk.email.lead` на `[[++form-mail]]`, тема — «Заявка з головної сторінки» или «Заявка зі сторінки «<menutitle>»», после отправки редирект на «Дякуємо за запит» (1479/1478). Лид в Bitrix24 через `rest.php` отправляется только с боевого домена.
- Цифры, заголовки и подписи меняются в lexicon-файлах; после правки — очистить кэш.
